# E-commerce Platform with AI Assistant

An e-commerce platform designed for local shops, featuring an AI assistant that can answer customer questions and place orders on their behalf.

## Features
- Product browsing and shopping cart
- Order management
- AI assistant that handles customer requests and places orders via chat

## Technologies Used
- HTML, CSS, JavaScript
- Node.js, Express.js
- MySQL
